# Gujarat Bole Che

Modern Blogger theme and content automation project for Gujarat Bole Che.

## Safety
- No Blogger credentials or OAuth tokens are stored in this repository.
- Automated publishing remains disabled until Blogger OAuth is configured and a test draft is verified.
- Content pipeline is designed for original, source-backed summaries; no article copying or artificial traffic.

## Components
- `blogger/theme.xml` — modern Blogger-compatible theme v1
- `blogger/theme-upgrade.css` / `.js` — interactive design layer
- `automation/` — research, generation and Blogger publishing components
- `config/topic_registry.json` — editorial topic registry
